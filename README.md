# l2d-viewer

To use this package, you must also import [Live2D Cubism Core](https://cubism.live2d.com/sdk-web/core/05/live2dcubismcore.min.js) alongside it.

Breaking changes can happen on any version, this project does not use semver.
Lock your changes to a specfic commit or version always.

## Usage

Plain HTML:
```js
<script src="https://cdn.jsdelivr.net/npm/l2d-viewer@<version>/dist/live2d-viewer.iife.js"></script>
```

MediaWiki:
```js
mw.loader.load("https://cdn.jsdelivr.net/npm/l2d-viewer@<version>/dist/live2d-viewer.iife.js");
```
